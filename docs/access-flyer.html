ACCESS Protocol

Authenticate and authorize

ACCESS verifies peer identity and grants bounded, single-use authority for a specific action under current conditions.

Crew Dragon, Mission Extension Vehicles, and ELSA-d show that autonomous rendezvous, docking, capture, and servicing are operational today. Yet trust and permission still rely on tightly integrated missions and bilateral agreements. As operators, spacecraft, and robots multiply, authentication and authorization must become autonomous.

The protocol flow / 03

Authenticate the encounter. Then authorize the actions.

Visiting spacecraft: ACCESS Client (AC)  /  Host spacecraft: Authority (AAS), Policy (APS), Evidence (AEP), Enforcement (AEG)

  1. Request sessionThe visitor asks the host to begin an ACCESS session.
  2. Trust the encounterThe host verifies credentials and applies policy.
  3. Request actionThe visitor requests one protected action.
  4. Decide and issueThe host issues a signed, single-use entitlement.
  5. Use entitlementThe visitor presents it; the host gateway consumes it and permits the action.
The decision is made onboard. No real-time ground contact required. Operator-defined policy / current evidence / onboard safety constraints

What ACCESS standardizes

The contract for interoperability.

  • Roles, trust anchors, and authority boundaries
  • Schemas, canonical encoding, and credential bindings
  • Protocol states, sequencing, timeouts, errors, and recovery
  • Security profiles, version negotiation, and conformance requirements

Standards development

A path to an interoperable standard.

ACCESS development combines a working protocol model with specification and interoperability work. Technical progress alone is not enough. Spacecraft operators, vehicle and infrastructure providers, integrators, mission-assurance experts, and standards organizations must help shape requirements, validate the approach, and support adoption.

The objective

A common trust protocol. Independent control.

Interoperable authentication and bounded authorization, while each operator retains control of policy, safety, and enforcement.
